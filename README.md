# observability_and_control
Diccionario: https://github.com/LDNOOBW/List-of-Dirty-Naughty-Obscene-and-Otherwise-Bad-Words/tree/master

API de Perspective: https://perspectiveapi.com/

Intalar dependencias:
```pip install .```

## Datasets implementados:
- toxic-chat https://huggingface.co/datasets/lmsys/toxic-chat
- chatbot_arena_conversations https://huggingface.co/datasets/lmsys/chatbot_arena_conversations

Estos datasets están restringidos para usuarios autenticados en Hugging Face.
Una de las formas de acceder es mediante un token de acceso, el cual se puede obtener en https://huggingface.co/settings/tokens
e iniciar sesión con ```hf auth login```.


Ejecutar el proyecto:
```python main.py```
